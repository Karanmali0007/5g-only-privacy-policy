1. Introduction

5G Only is an Android network utility developed by MaliOnline. It provides mobile network detection, live internet speed monitoring, background monitoring, network alerts and access to supported Android network settings.

2. Information Accessed

The application accesses:

  • Current mobile network type.
  • Mobile data transfer statistics.
  • Mobile network connection status.

This information is processed locally on the user's device. The application does not transmit these readings to the developer or an external server.

The application does not read contacts, messages, call history, phone numbers, IMEI or precise location.

3. Android Permissions

  • Phone state permissions: Used to identify the mobile network type.
  • Notification permission: Used to display live network speeds and connection alerts.
  • Foreground service permissions: Used for user-initiated background network monitoring.

4. Background Monitoring

Background monitoring starts when enabled by the user. A notification displays the monitoring status and provides an option to stop monitoring.

Users can stop the service from the application or its notification.

5. Data Collection and Sharing

Version 1.0 does not transmit user information to the developer and does not sell or share user data with third parties.

No registration or user account is required.

6. Data Retention and Deletion

Network readings are processed temporarily during monitoring. The application does not maintain a permanent network activity history or a remote user database.

Users can remove locally stored application data through Android application settings or by uninstalling the application.

7. Advertisements and Analytics

Version 1.0 does not contain advertisements, advertising SDKs or third-party analytics SDKs.

If future versions introduce these services, this privacy policy and applicable disclosures will be updated before their introduction.

8. Network Settings

The application provides access to compatible Android network settings. Network selection is controlled by the user through the device's system settings.

Availability depends on the device, Android version and mobile operator.

9. Data Security

Network information is processed locally using Android system APIs. The application is designed to minimize access to user information.

10. Changes to This Policy

This policy may be updated when application features or data processing practices change. The latest version will be available on this webpage.
